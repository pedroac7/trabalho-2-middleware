==================================================
SIGNIFICADO DOS PARAMETROS
==================================================

Gateway:
gateway.Main <gatewayProtocol> <gatewayPort> <heartbeatPort> <epsilonMs> <internalClientsProtocol>

Exemplo:
gateway.Main http 8080 9090 100 http

- gatewayProtocol = protocolo de negocio exposto pelo gateway: http, tcp ou udp
- gatewayPort = porta de negocio do gateway
- heartbeatPort = porta do HeartbeatReceiver
- epsilonMs = epsilon do Clock-Bound Wait
- internalClientsProtocol = protocolo esperado para clients internos; na pratica o GatewayService usa o protocolo anunciado por heartbeat

Validador / Repositorio:
validador.Main <serviceProtocol> <servicePort> <gatewayHost> <gatewayHeartbeatPort>
repositorio.Main <serviceProtocol> <servicePort> <gatewayHost> <gatewayHeartbeatPort>

Exemplo:
validador.Main tcp 8081 127.0.0.1 9090

- serviceProtocol = protocolo de negocio anunciado no heartbeat: http, tcp ou udp
- servicePort = porta de negocio da instancia
- gatewayHost = host do gateway
- gatewayHeartbeatPort = porta do HeartbeatReceiver do gateway
