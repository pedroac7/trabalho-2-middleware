============================================================
0) PREPARAÇÃO GERAL
============================================================

Execute uma vez antes dos testes, a partir da raiz do repositório:

cd middleware-core
mvn install -DskipTests

cd ..\sistema-distribuido-precos\api-gateway
mvn -q -DskipTests package
mvn -q dependency:copy-dependencies

Depois volte para a raiz se quiser seguir os comandos abaixo:

cd ..\..

============================================================
1) FLUXO HTTP
============================================================

TERMINAL 1 - VALIDADOR 1 HTTP

cd sistema-distribuido-precos\validador-precos
mvn exec:java "-Dexec.mainClass=validador.Main" "-Dexec.args=http 8081 localhost 9090"


TERMINAL 2 - VALIDADOR 2 HTTP

cd sistema-distribuido-precos\validador-precos
mvn exec:java "-Dexec.mainClass=validador.Main" "-Dexec.args=http 8084 localhost 9090"


TERMINAL 3 - REPOSITORIO 1 HTTP

cd sistema-distribuido-precos\repositorio-precos
mvn exec:java "-Dexec.mainClass=repositorio.Main" "-Dexec.args=http 8082 localhost 9090"


TERMINAL 4 - REPOSITORIO 2 HTTP

cd sistema-distribuido-precos\repositorio-precos
mvn exec:java "-Dexec.mainClass=repositorio.Main" "-Dexec.args=http 8083 localhost 9090"


TERMINAL 5 - GATEWAY HTTP

cd sistema-distribuido-precos\api-gateway
java -cp "target/classes;target/dependency/*" gateway.Main http 8080 9090 50 http
